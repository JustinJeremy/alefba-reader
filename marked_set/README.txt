MARKED ALPHABET SHEETS - TEST ONLY, never train on these.

A photo of a whole handwritten alphabet sheet with ONE letter marked. The app reads only that letter.
  real/         the original photos: a blue arrow (mim), a blue box (ye), a yellow highlighter (eyn)
  recoloured/   the same photos with the mark recoloured red, orange, green, purple and pink
  sheet_without_mark.jpg   the same sheet with no mark: the app must ask for a mark or a selection
                           (no number at the start of the name, so score_testset.py skips it)

File names start with the class number of the marked letter, like real_photos/.
Score them:   python score_testset.py marked_set
